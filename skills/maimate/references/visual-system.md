# 麦之宝库 · 视觉与交互

仅在用户要求界面、效果图或视觉设计时读取。普通点餐无需生成图片。参考 [三屏概念图](../assets/maimate-product-v0.2.png)，它是合成示意，不能当成真实商品或官方现有截图。

受众：日常单人与多人点餐。用途：选定并完成这一餐。调性：playful。

## 结构

目标信息架构是点餐、宝库、订单、我的。App 集成遵循实际宿主导航。点餐提供直接点、帮我选、老样子；宝库分常点组合、我的优惠、想尝试；订单强调履约；我的管理口味与学习。所有选餐路径共享草稿和核价。

价格未核验时显示“组合草稿”“待核价”，提供选择门店或补齐条件的动作。只有当前完整核价后才出现真实实付及进入交易动作。示意图中的“—”是价格占位，不是免费。

## 识别元素

首页用几扇错落的小金拱门表现可选食物；个人组合用双拱；选中餐品只保留一扇门。原创建模，暖色哑光细线，食物是主角。菜单保持易扫读列表，不为每个商品套金色卡片。

不使用宫殿背景、彩色光晕、抽卡等级、渐变标题、虚构指标或全屏居中的广告首屏。没有假手机边框、假浏览器壳或表情符号功能图标。功能图标统一 Lucide 或宿主现有单一图标系统。

## Tokens 先于界面代码

UI 颜色只使用 OKLCH，锚色相 85；以带色倾向的暖中性色为主体，金色强调目标不超过视口 3%。原生食物图片保留真实色彩，不受 UI token 限色要求影响。

| token | 建议初值 |
| --- | --- |
| canvas | oklch(97% .012 85) |
| surface | oklch(94% .015 85) |
| ink | oklch(25% .025 85) |
| ink-muted | oklch(43% .025 85) |
| control-border / focus | oklch(52% .025 85) |
| accent | oklch(80% .15 85)，配深色 ink |
| font-display | Bricolage Grotesque |
| font-body | Noto Sans SC |
| space | 4 / 8 / 12 / 16 / 24 / 32 / 48，转为语义 token |
| duration | 120 / 220 / 420ms |
| ease-out | cubic-bezier(.16,1,.3,1) |

所有颜色、字体、间距、圆角与动效参数进入 :root / @theme 或原生语义 token。网页组件只通过 var(--token) 引用；样式表第一行使用 design 戳描述布局、playful、字体配对与锚色相 85。遵守目标项目更严格的设计规约。

标题正体 700，正文 400。以 16px 为基础、1.25 比例，最多五档字号；正文不低于 14px。font-display: swap。重点左对齐，分区留白有节奏，不等宽三卡、不套卡、不用单侧色条。

## 反馈与可达性

召唤只做一次不超过 500ms 的入场，仅 transform 与 opacity。减少动态效果时塌缩为 150ms 透明度变化。复购和赶时间可以直接静态呈现，不强制观看。无无限背景动画。

按钮、导航和 CTA 文案保持一行；加载超过 150ms 才出现指示，已知布局使用骨架。成功保持安静，可逆修改提供 Undo。错误直接指出影响用户选择的事实，不隐藏在装饰中。

正文对比度至少 4.5:1，大字及功能边界至少 3:1，焦点环即时出现。至少验证 320 / 375 / 414 / 768 / 1440 宽度、最大系统字号、屏幕阅读顺序与 reduced-motion。原生点击区按平台至少 44pt / 48dp；不依赖 hover 或拖动完成任务。网页使用 overflow-x: clip，避免固定控件遮挡内容。

生成效果图只证明视觉方向，不能宣称已经通过真实界面的对比度、响应式或交互测试。真商品图片与金额来自验证数据；生成素材必须标示为概念或演示。
